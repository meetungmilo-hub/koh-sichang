# เที่ยวสีชัง

เว็บไซต์ต้นแบบสำหรับวางแผนแพ็กเกจท่องเที่ยวชุมชนและส่งคำขอจอง Skylab บนเกาะสีชัง

## เริ่มต้นใช้งาน

ต้องติดตั้ง [Bun](https://bun.sh/) และ Node.js 22.12 ขึ้นไปก่อน

```sh
bun install
bun run dev
```

เปิด URL ที่แสดงในเทอร์มินัลเพื่อดูเว็บไซต์ระหว่างพัฒนา

## คำสั่งที่ใช้บ่อย

```sh
bun run build    # สร้างไฟล์สำหรับนำไป deploy
bun run preview  # ดูตัวอย่าง build ในเครื่อง
bun run lint     # ตรวจรูปแบบและข้อผิดพลาดของโค้ด
bun run test     # รันทดสอบ
```

## หมายเหตุเกี่ยวกับต้นแบบ

- รายละเอียดแพ็กเกจ ราคา รอบ Skylab และที่พักเป็นข้อมูลตัวอย่างที่ต้องยืนยันกับผู้ให้บริการก่อนเปิดใช้งานจริง
- แบบฟอร์มจองยังไม่ส่งข้อมูลไปยังระบบหลังบ้านและไม่ได้รับชำระเงินจริง
- เส้นทางและเรื่องเล่าควรตรวจสอบร่วมกับชุมชนก่อนเผยแพร่

## เทคโนโลยี

- React และ TypeScript
- TanStack Start และ TanStack Router
- Vite, Tailwind CSS และ Nitro
